# --- the data itself -------------------------------------------------------------
# Three parquet files, 3 GB. pyarrow reads them; the corpus fits in RAM on this box,
# so there is no streaming layer to build.
numpy
pandas
pyarrow

# --- chemistry ------------------------------------------------------------------
# RDKit is the whole game: SMILES parsing, canonicalisation, InChIKey, Morgan
# fingerprints, formula and exact-mass arithmetic. The competition metric compares
# structures, so every candidate has to pass through it.
rdkit
# Mass-spectrometry side: spectrum objects, peak filtering, and the cosine /
# modified-cosine similarities that every public baseline is built on. Pulls its own
# pinned numpy range, so install it in the same pass as numpy rather than after.
matchms

# --- modelling ------------------------------------------------------------------
scikit-learn
scipy
# GPU build, because FPNet trains here: this box has an NVIDIA L40 (47.6 GB) behind
# driver 535 / CUDA 12.1, and the cu126 wheels run on it through CUDA minor-version
# compatibility. Install it from the PyTorch index, not PyPI:
#
#   pip install --index-url https://download.pytorch.org/whl/cu126 \
#       --extra-index-url https://pypi.org/simple "torch==2.14.1+cu126"
#
# Two traps met getting there. A bare `pip install torch --index-url .../cu121` is a
# no-op when a *newer* CPU build is already present (2.14.1+cpu outranks 2.5.1+cu121),
# so pin the exact `+cu126` version. And `--no-deps` installs the wheel without the
# nvidia-* runtime packages, which then fails at import with
# `libcudnn.so.9: cannot open shared object file`.
torch==2.14.1+cu126
