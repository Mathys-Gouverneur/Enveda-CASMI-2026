# Data layout

Four tiers, by where the bytes came from. Nothing here mixes — check the directory before
you trust a file.

| Directory | Origin | Modify? | In git? |
|---|---|---|---|
| `raw/` | Provided by Kaggle | **Never** | **No** — a symlink, gitignored |
| `external/` | Third-party, vendored from Kaggle datasets | **Never** | Yes, with `PROVENANCE.md` |
| `candidates/` | Structure databases and model weights refetched from Kaggle | **Never** | **No** — gitignored, tens of GB |
| `processed/` | Generated by our own scripts | Regenerate, don't edit | **No** — gitignored |

## `raw/` — a symlink, on purpose

```
data/raw -> /data/mgr/enveda-casmi/raw
```

`/data/mgr/enveda-casmi` is mode `700`, readable by `mgr` alone, on the same volume and
with the same permissions as `/data/mgr/rsna-knee`. The bytes live there rather than in
the repository for two reasons: `/data` has the room (882 GB free against 228 GB on
`/working`), and `train.parquet` must not be one `git add -A` away from a remote —
it is CC BY-NC 4.0, and `test.parquet` carries its own separate noncommercial
restriction.

Populate it with [`../scripts/download_data.sh`](../scripts/download_data.sh). That script
refuses to run until the competition rules are accepted in a browser, because the API
answers `403` on every data endpoint until then without saying why.

Three files: `train.parquet` (3.03 GB), `test.parquet` (4.8 MB),
`sample_submission.csv` (43 KB). See [`../docs/competition.md`](../docs/competition.md)
for what is in them.

## `external/`

Third-party inputs small enough to version, one directory per Kaggle dataset, named
`<owner>-<slug>`, each with a `PROVENANCE.md` recording source URL, author, **licence**,
download date and checksums.

The licence field is not bookkeeping here. The hosts have ruled that external data under
a commercial-use-restricting licence can get a solution removed from the leaderboard
entirely — so a dataset arrives in this directory only once its licence is written down.

## `candidates/`

The large shared inputs the public stack runs on — COCONUT, PubChemLite, ChEBI/LIPID MAPS,
the PubChem popularity prior (105.9 M rows), and the FPNet / ICEBERG / GLACIER / DreaMS
checkpoints. Gitignored: tens of GB, every one refetchable with a single
`kaggle datasets download`.

What is worth versioning is the *manifest* — which datasets, which version, which licence —
and that belongs in `docs/`, not here.

## `processed/`

Derived artefacts, gitignored, **always safe to delete** — everything here is regenerated
by a script, precisely so a stale derived file cannot outlive the code that made it.
Currently nothing writes here.
