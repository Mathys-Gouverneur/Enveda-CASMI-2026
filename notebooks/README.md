# Notebooks

`external/` holds public Kaggle kernels, vendored unmodified — see
[`external/README.md`](external/README.md).

Everything directly in this directory is ours. Notebooks here are for exploration and for
producing a number or a figure that then gets written down in `docs/`; anything that needs
to run twice the same way belongs in `src/casmi/` with an entry point in `scripts/`.
